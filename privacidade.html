Política de privacidade — Zé do Bolso Estúdio

Atualizada em 23 de novembro de 2026.

Quem usa

O aplicativo é usado apenas pelo dono do canal Zé do Bolso, no próprio computador, para administrar o próprio canal.

Quais dados acessa

  • Dados do canal do próprio usuário no YouTube: lista de vídeos, títulos, descrições, playlists e estatísticas (YouTube Data API e YouTube Analytics API).
  • Envio, agendamento e edição de vídeos e comentários no próprio canal.

Como usa e guarda

Os dados ficam só no computador do dono do canal, para mostrar os números do canal e agendar envios. O token de acesso fica guardado localmente e nunca é enviado a terceiros.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros. Nenhum dado de espectadores é coletado.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Pelo canal Zé do Bolso no YouTube.
